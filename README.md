# Система сбора и валидации телеметрии

## Описание
Система собирает телеметрию из 4 источников (раз в секунду, от 100 до 600 объектов от каждого). 
Валидные значения (числа и булевы) сохраняются в базу SQLite. 
Невалидные значения логируются по 20 трендам с использованием самописного WAL-журнала. 
Для каждого тренда действует постоянное окно видимости — 3600 последних записей.

## Технологии
- **Python** (сбор, валидация, SQLite, WAL)
- **JavaScript (Node.js)** (симулятор источников данных)
- **SQLite** (хранение данных)
